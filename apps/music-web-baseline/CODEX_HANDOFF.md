# Moodify Music — Codex 接手说明

这是 Moodify 三个平台中的音乐平台前端。当前版本已完成首页视觉与核心交互，可作为后续真实业务接入的前端基线。

## 已完成

- Moodify 品牌 Logo 与蓝紫深色视觉系统
- 每日推荐、分类筛选、搜索结果
- 播放、暂停、上一首、下一首与进度反馈
- 收藏歌曲、当前曲目和播放器状态
- 创作者入口、上传入口
- 桌面端与移动端响应式布局

## 本地启动

```bash
npm install
npm run dev
```

生产构建：

```bash
npm run build
```

## 关键文件

- `app/page.tsx`：页面结构、演示曲目与交互状态
- `app/globals.css`：完整视觉和响应式样式
- `app/layout.tsx`：页面元信息
- `public/moodify-logo.png`：用户提供的正式 Logo
